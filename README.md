# Time-Series Analysis of Malaria

Clustering-based time-series analysis of malaria incidence and mortality trends across **46 Sub-Saharan African countries from 2000–2023**.

This repository contains the **R code, data-source documentation, processed datasets, and analytical outputs** supporting the manuscript. The study applies clustering-based time-series methods to characterize similarities and heterogeneity in malaria trends across countries and to examine their relationships with selected **sociodemographic, climatic, geographic, and health-system characteristics**.

## Methods

The analysis includes:

- Data cleaning, harmonization, and preparation of malaria and auxiliary datasets
- Time-series analysis of malaria incidence and mortality rates
- Pairwise **cross-correlation-based distance** to quantify similarity between country-level time series
- **Multidimensional scaling (MDS)** to visualize similarities and differences in malaria trajectories
- **Hierarchical clustering** to identify groups of countries with similar malaria trajectories
- Assessment of clustering correspondence using **cophenetic correlation** and **Baker's Gamma correlation**
- Network-based analysis and visualization of relationships among malaria indicators and complementary sociodemographic, climatic, geographic, and health-system variables
- Generation of statistical outputs, manuscript figures, and tables

## Repository Structure

### `Data Sources/`

Documentation and links to the publicly available data sources used in the study, including sources for malaria, sociodemographic, climatic, geographic, and health-system data.

### `Code/`

R scripts used throughout the analytical workflow, including:

- Data cleaning and harmonization
- Time-series preparation and transformation
- Distance calculation and clustering
- Multidimensional scaling and hierarchical clustering
- Cluster comparison and validation
- Network analysis
- Statistical analysis
- Generation of figures and tables

### `Raw_Data/`

Contains the **raw datasets** obtained from the publicly available data sources documented in `Data Sources/`. These files represent the original data before cleaning, harmonization, transformation, or analysis.

### `R_Data/`

Contains **processed and summarized datasets prepared for analysis in R**. These datasets are generated from the raw data through the data-cleaning and preprocessing workflow and are used as inputs for subsequent statistical and time-series analyses.

### `R_Output/`

Contains **analytical outputs generated by the R scripts**, including model results, statistical summaries, clustering results, and other intermediate or final outputs supporting the manuscript.

### `Plots/`

Contains **figures and visualizations generated from the analysis** for use in the manuscript, including time-series plots, clustering visualizations, network plots, and other graphical outputs.

## Reproducibility

The analysis was conducted primarily in **R** and is organized as a reproducible workflow:

**Raw data → Data cleaning and processing → Analysis-ready R data → Statistical and time-series analysis → Outputs and figures**

The repository separates raw data from processed data and analytical outputs to facilitate transparency, reproducibility, and organization of the analysis.

The time-series clustering methodology was adapted from the framework developed by **Dr. Alexander Kirpich** and collaborators for comparing multivariate epidemiological dynamics. Additional information about this methodological framework and related work is available through the [Kirpich Lab](https://alexanderkirpich.com/lab).

## Study Scope

The analysis focuses on **46 Sub-Saharan African countries** and covers the period **2000–2023**. Malaria incidence and mortality trends are analyzed alongside selected contextual variables to characterize geographic and temporal heterogeneity across the region.

The auxiliary variables are used primarily to **contextualize and compare observed malaria trajectories**, rather than to infer direct causal relationships.
